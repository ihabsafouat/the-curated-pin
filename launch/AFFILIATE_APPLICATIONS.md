# Affiliate applications — Birthday launch

## Stage A — production site live

Apply to:

- Impact
- CJ Affiliate
- Awin
- Etsy Affiliates

Prepare before applying:

- final production URL
- About/editorial policy page
- affiliate disclosure
- privacy policy and terms
- 10+ high-quality public posts where possible
- clear Pinterest/social profile(s)
- concise publisher description: Birthday/celebration planning, practical party ideas, games, printables and shopping guidance

## Stage B — merchant programs

Prioritize merchants that match real article sections:

- Walmart (Impact)
- Minted (Impact)
- Oriental Trading (Impact; approval requirements apply)
- Michaels (CJ)
- relevant Etsy listings through Etsy Affiliates

Never insert a merchant because it pays more if the product does not fit the reader's current problem.

## Stage C — Amazon

Wait until the site has a strong public content base and traffic capable of generating qualifying sales. Amazon currently requires three qualifying sales within the first 180 days before application review and recommends robust original public content.

## Article-level placement examples

- Outdoor movie → projector/screen/string lights only if genuinely useful
- Craft party → relevant craft supplies
- First birthday → invitations/tableware/photo display items with safety awareness
- Party games → equipment only for games that actually require it
- 18th birthday → invitations, photo accessories, decor; no alcohol/age-restricted affiliate promotion
